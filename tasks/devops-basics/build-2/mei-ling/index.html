Robot Club

Thursdays, 3 to 4.30 pm, in the computer lab. We build and code small robots.

What we do

  • Weeks 1 to 3: draw a robot and plan its moves.
  • Weeks 4 to 6: code the moves in blocks.
  • Week 7: show a parent or friend.
