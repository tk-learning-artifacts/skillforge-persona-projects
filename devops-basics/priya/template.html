OnceMake it your template

  1. Make a new public repository called team-site-template.
  2. Unzip the download. Use Add file, then Upload files, and drag everything in.
  3. Check that .github/workflows/static.yml is there. Folders starting with a dot are often hidden. If it is missing, use Add file, then Create new file. Type the path as the name and paste it in.
  4. In Settings, tick Template repository.

Per teamCopy and set up

  1. Use this template, then Create a new repository. Public, named like cca-team-3. It starts with one commit.
  2. Settings, Pages: source GitHub Actions. Merge anything to main and the site goes live.
  3. Settings, Rules, Rulesets: a branch ruleset on the default branch. Turn on "Require a pull request before merging", with 1 required approval.
  4. Settings, Collaborators: add members aged 13 or over.
  5. Open one New page issue per member, and one for task 3.

# Team site template

A small website your team builds together, one page each.
Every change goes through a pull request. When one is merged, the site updates itself.

## Set up (teacher, once per team)

1. Click **Use this template**, then **Create a new repository**. Make it public.
2. Settings > Pages > Source: **GitHub Actions**. The workflow is already here.
3. Settings > Rules > Rulesets > New branch ruleset, for the default branch:
   **Require a pull request before merging**, with 1 required approval.
4. Settings > Collaborators: add each member who is 13 or older.
5. Open one issue per page, using the **New page** issue template.

## Your 3 tasks

1. **Make your page.** Copy `starters/copy-me.html`, fill it in, and link it from `index.html`.
2. **Review a teammate's page.** Use the checklist in their pull request. Approve, or ask for one change.
3. **Fix the home page together.** Change the title and the first line of `index.html` to say what your site is for.

## How to make a change, all in the browser

1. Open the file on GitHub and click the pencil to edit it.
   To add a file, use **Add file** > **Create new file**.
2. Click **Commit changes**. Choose to create a new branch. Name it after your task.
3. Click **Propose changes**, then **Create pull request**. Fill in the checklist.
4. When a teammate approves, click **Squash and merge**, then **Delete branch**.
5. Open the **Actions** tab to watch the deploy. Then open your live site.

## Rules

See `how-we-work.html`. It is part of your site, so visitors can see how you work too.

.github/workflows/static.yml GitHub's Static HTML starter, unchanged
# Simple workflow for deploying static content to GitHub Pages
name: Deploy static content to Pages

on:
  # Runs on pushes targeting the default branch
  push:
    branches: ["main"]

  # Allows you to run this workflow manually from the Actions tab
  workflow_dispatch:

# Sets permissions of the GITHUB_TOKEN to allow deployment to GitHub Pages
permissions:
  contents: read
  pages: write
  id-token: write

# Allow only one concurrent deployment, skipping runs queued between the run in-progress and latest queued.
# However, do NOT cancel in-progress runs as we want to allow these production deployments to complete.
concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  # Single deploy job since we're just deploying
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v5
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          # Upload entire repository
          path: '.'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v5

## What I changed

Closes #

## Reviewer, please check

- [ ] The page opens from the home page link.
- [ ] Every link on the page works.
- [ ] No real names, emails, photos, class numbers or school details.
- [ ] No keys, passwords or tokens.
- [ ] Words a Sec 1 student would know. Sentences short enough to read aloud.
