Spot the conflict

Two students change the same sentence. The class decides how to merge.

You need: 2 sticky notes, a whiteboard with one sentence on it: The canteen opens at 7.30 am.

Steps (5 minutes)

  1. Two volunteers each get a sticky note. Each rewrites the sentence their own way, without looking.
  2. Stick both notes under the sentence.
  3. Ask: which one wins? Can we keep both?
  4. Write the agreed sentence. Rub out the other two.
  5. Say: Git calls this a merge conflict. A person has to choose, because Git can't.
