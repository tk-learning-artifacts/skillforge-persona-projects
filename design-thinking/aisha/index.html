The Cool-Down Dock

A cardboard stand with a micro:bit in it. You park a glue gun after you unplug it. The display drains while the gun cools, then shows a tick. If you lift the gun too early, it beeps.

I'm Aisha. I teach design and making in a school makerspace. My Sec 1 classes use hot glue guns every week, and pack-up is where things go wrong. I took one problem through one full loop: empathise, define, ideate, prototype and test. Then I built version 2.

Step 1 Empathise

I started with a hunch: students leave glue guns on. I was wrong about that. I interviewed three people for 10 minutes each. I asked about the last time, never "would you use…".

  • Our lab technician"After most lessons I find two or three guns still hot in the tool tray. The tray has melt marks."
  • Sec 1 student A"I unplug it when the bell goes. Then I hold my hand near the tip to feel if it's cold. It's hard to tell."
  • Sec 1 student B"Nobody wants to be last out. We just put everything in the tray."
  • Technician, again"The cool-melt ones are still hot. They're just less hot."

The technician was right about cool-melt guns. Bostik's own figures put its Craft Cool Melt gun at 125 to 135°C. Its hot-melt guns run at 175 to 200°C. Swapping guns would not fix this.

What they said they wanted

"More time to pack up." "Guns with a light on them."

What they needed

A way to see that a gun is still hot, without touching it, in the last 5 minutes of a lesson.

The guns were unplugged. My hunch was wrong. The real problem is that a hot gun and a cold gun look the same.

Step 2 Define

Sec 1 makers packing up need to see when a glue gun is safe to put away, because a hot gun looks the same as a cold one.

My first draft was "Students need a timer for their glue guns." That hides a solution. A timer is one answer. So is a rule, a colour sticker or a rack.

How might we make a glue gun's heat visible at pack-up?

Step 3 Ideate

My Sec 1s and I wrote exactly 20 ideas on sticky notes in 15 minutes. No judging. Then we sorted them into four themes. The two picked ideas are outlined.

Routines

  1. 1Unplug guns 10 minutes before the bell
  2. 2A glue gun captain for each table
  3. 3Guns stay on the bench until the next class
  4. 4A pack-up song that lasts the cooling time
  5. 5Teacher checks every gun at the door

Materials

  1. 6A sticker that changes colour with heat
  2. 7A metal cooling rack
  3. 8A heat-proof tray instead of plastic
  4. 9A silicone cap for the tip
  5. 10Only use cool-melt guns

Signals

  1. 11A dock that counts down the cooling time
  2. 12A light that stays on until the gun is cold
  3. 13A buzzer if a gun goes in the tray hot
  4. 14Measure the tip with a sensor
  5. 15A sign on the wall: "Unplugged at…"

Wild ones

  1. 16A fan that cools guns faster
  2. 17Guns that switch off on their own
  3. 18Glue with no heat at all
  4. 19Glue time only in the first half
  5. 20A robot arm that packs the guns

We picked two. Idea 1 costs nothing, so it starts next week anyway. Idea 11 is the one I could prototype in one lesson. It tests something I did not know: will students wait if they can see the time left?

Idea 14 died fast. The micro:bit's temperature sensor sits inside its processor. It gives roughly the air temperature, not the tip's. So we time the cooling instead of measuring it.

The one assumption the prototype tests

If students can see how much cooling time is left, they will leave the gun in the dock until it is done.

Step 4 Prototype

Version 1 took 90 minutes: corrugated card, masking tape, one micro:bit V2, a battery pack and a ceramic tile. The gun lies in a cardboard cradle. Its nozzle rests on the tile, never on card.

Version 1: the light sensor

The micro:bit lies face up under a hole in the cradle floor. The micro:bit can sense light with its LED display. When the gun covers the hole, the reading drops and a 10-minute countdown starts. Our technician chose 10 minutes for our guns. Your guns may need a different time, so it's a setting at the top of the code.

Version 1 code (MakeCode JavaScript) 
// Cool-Down Dock, version 1. A dark reading means a gun is parked.
let COOL_MINUTES = 10
let parkedAt = -1
basic.forever(function () {
    if (input.lightLevel() < 40) {
        if (parkedAt < 0) {
            parkedAt = input.runningTime()
        }
        let left = Math.ceil((COOL_MINUTES * 60000 - (input.runningTime() - parkedAt)) / 60000)
        if (left > 0) {
            basic.showNumber(left)
        } else {
            basic.showIcon(IconNames.Yes)
        }
    } else {
        parkedAt = -1
        basic.clearScreen()
    }
})

Try it in the simulator and you'll spot the big problem in about ten seconds. I didn't. My testers did.

Step 5 Test

I tested version 1 with three people: student A, whom I had interviewed, the technician, and student C from another class. I said one line, "Use it like it's the end of a lesson," and then I only watched and wrote.

  • Note 1. Student C laid the gun in and asked, "Where's the timer?" The gun was lying on top of the display.
  • Note 2. Student A lifted the gun after 3 minutes to see the number. The screen went blank. Nothing warned her.
  • Note 3. The technician waved a hand over the empty dock. A countdown started.
  • Note 4. When someone switched off the lights for the projector, the empty dock started counting.
  • Note 5. At switch-on it flashed a 10 every time. The micro:bit's first light reading is always 0, so it thought a gun was parked.
  • Note 6. The technician: "I need to see from the door if any gun is still hot."

Then the class critiqued it with "I like, I wish, What if". These are the notes that changed something.

I like

"The tile. The tip isn't touching anything." "It's one stand per gun, so you know which one."

I wish

"I wish I could see it with the gun in." "I wish it told you off if you lift it early."

What if

"What if the gun's weight starts it, not the dark?" "What if the lights go down like a phone battery?"

Version 2: what changed and why

  • Notes 3 to 5The light sensor is gone. Two foil pads sit under a foam pad with a hole in it. The gun's weight presses them together, which joins pin 0 to GND. A hand or the room lights can't do that.
  • Note 1The micro:bit moved to the front wall, tilted up. You can see it with the gun in.
  • What ifThe display drains like a battery: 25 lights, one goes out every 24 seconds. No numbers to read.
  • Note 2Lift it early and you get a cross and two low beeps. Put it back and the count starts again from full. Starting over is the safe mistake.
  • I wishA tick and a high beep when it's done. Every sound also shows on the display, so a student who can't hear it still sees it.
  • Note 6Not fixed. See what I'd change.
Version 2 code (MakeCode JavaScript) 
// Cool-Down Dock, version 2. Foil pads on P0 and GND.
// The gun's weight presses them together.
const COOL_MINUTES = 10
const TOTAL = COOL_MINUTES * 60000
let parkedAt = -1
let done = false

// Light the last "count" of the 25 LEDs. They go out from the top.
function showLeft(count: number) {
    for (let i = 0; i < 25; i++) {
        if (i >= 25 - count) {
            led.plot(i % 5, Math.idiv(i, 5))
        } else {
            led.unplot(i % 5, Math.idiv(i, 5))
        }
    }
}

basic.forever(function () {
    if (input.pinIsPressed(TouchPin.P0)) {
        if (parkedAt < 0) {
            parkedAt = input.runningTime()
            done = false
            music.playTone(523, music.beat(BeatFraction.Quarter))
        }
        let left = TOTAL - (input.runningTime() - parkedAt)
        if (left > 0) {
            showLeft(Math.ceil(left * 25 / TOTAL))
        } else if (!(done)) {
            done = true
            basic.showIcon(IconNames.Yes)
            music.playTone(988, music.beat(BeatFraction.Half))
        }
    } else {
        if (parkedAt >= 0 && !(done)) {
            // Lifted while still cooling.
            basic.showIcon(IconNames.No)
            music.playTone(262, music.beat(BeatFraction.Whole))
            music.playTone(262, music.beat(BeatFraction.Whole))
            basic.pause(3000)
        }
        parkedAt = -1
        done = false
        basic.showIcon(IconNames.SmallSquare)
    }
})

I tested version 2 with the same three people. All three left the gun in until the tick. Student C watched the lights go out and said, "It's like a loading bar backwards." The technician could read it from 2 metres, but not from the door.

    What I'd change

    The technician's wish is still open. One dock tells you about one gun, standing next to it. She wants to know from the door. A class set of 10 docks also needs 10 micro:bits, and that's most of my kit.

    Next loop I'd test a "What if" from the critique. Each dock sends its state by radio to one micro:bit by the door. It shows how many guns are still cooling. I'd also test idea 1, the early unplug, on its own first. If it works, the dock may only be needed for the last few guns.

    One more doubt: three testers in my own room, who knew me. Version 2 needs a test in a real pack-up, with the bell going and 20 students.

    Safety

    • The dock is for guns that are already unplugged. It times cooling. It doesn't switch anything off.
    • The nozzle always rests on a ceramic tile, never on card.
    • The dock is a reminder, not a thermometer. Treat every gun in it as hot until it shows a tick.
    • Craft knives: steel ruler, cutting mat, cut away from your body. I cut the thick parts myself.
    • The foil pads carry only the micro:bit's own small battery current. Use the 2 × AAA pack, not mains.
