Starter: build your agent page

A half-made web page for campers aged 8 to 12. It has 3 TODOs: one in HTML, one in CSS and one in JavaScript. When all 3 are done, a button cracks a secret message.

  • Run the starter as it is
  • Print the task card
  • Copy the 3 files
  • How I run the session
  • Answer key

How campers get it

  1. Open the Raspberry Pi Code Editor and choose "Start coding HTML/CSS". No account is needed.
  2. Replace the code in index.html and styles.css with the files below.
  3. Use the Add file button to make script.js, then paste the third file.
  4. Press Run. The page shows, but the badges are in a column and the message stays secret.

Campers do not log in. Under 13s need a parent's permission for a Raspberry Pi Foundation account, and a 3-day camp is too short to collect forms. So at the end, each pair uses the editor's download button. I keep the files for our showcase.

Copying 3 files is fiddly for an 8-year-old. I pair each younger camper with an older one. The older one is the navigator and reads the steps. The younger one types.

The yellow lines are the TODOs. The copies here leave out the AI note, so campers paste only their own page.

script.js

// Find the secret message and the button on the page.
const secret = document.querySelector('#secret');
const button = document.querySelector('#decode');
const hidden = secret.textContent;

// TODO 3 (JavaScript): The message was hidden with a Caesar shift.
// Change the 0 to the right shift. Caesar's own shift is a good guess.
const shift = 0;

// Moves every letter back along the alphabet by the shift.
function decode(text) {
  const abc = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
  let answer = '';
  for (const letter of text) {
    const place = abc.indexOf(letter);
    if (place === -1) {
      answer = answer + letter;
    } else {
      answer = answer + abc[(place - shift + 26) % 26];
    }
  }
  return answer;
}

button.addEventListener('click', function () {
  secret.textContent = decode(hidden);
});

How I run it: one 90-minute camp block

20 campers, aged 8 to 12, in 10 mixed-age pairs. One laptop per pair.

  1. 0 to 10 min. Warm up with the table tap game from the Morse lab.
  2. 10 to 20 min. I show the finished agent page on the big screen. I click Decode it. Then I show the starter, with nothing working.
  3. 20 to 30 min. Pairs open the editor and paste the 3 files. Older campers navigate.
  4. 30 to 65 min. TODOs 1, 2 and 3. I walk round with the "check these first" list from the task card.
  5. 65 to 80 min. Mastermind challenges for pairs who finish. Pairs still working get my help.
  6. 80 to 90 min. Gallery walk. Half the pairs leave their pages open, and the rest go round cracking messages. Then swap.

Check: 10 + 10 + 10 + 35 + 15 + 10 = 90 minutes.

Why 3 levels on one card

  • Rookie

    About ages 8 and 9

    The hint gives the exact code to type and where. Success is a page that works.

  • Agent

    About ages 10 to 12

    The hint names the idea, such as "flexbox", and lets them find the line.

  • Mastermind

    Anyone who finishes

    New features with no step-by-step help. This keeps early finishers busy and away from other pairs' keyboards.

Every camper does the same 3 TODOs. Only the hints change. So the gallery walk still works: every page has a list, a row of badges and a decoder.

Test run with a colleague

My colleague and campers are made up, like me.

  • My colleague did all 3 TODOs in 14 minutes. Campers will take 2 to 3 times longer, so 35 minutes fits.
  • She typed display flex; without the colon. Nothing happened, and there was no error. I added "check the colon" to the task card.
  • She asked what "shift" meant. Rookies won't know either. The Rookie hint now says "try 3, like Caesar".
