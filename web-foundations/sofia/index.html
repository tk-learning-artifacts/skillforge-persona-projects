Case file: web foundations

Code Breakers HQ

A 3-page website for my secret codes holiday camp. Campers turn a Caesar wheel, flash Morse code on a lamp, then finish a starter page with their own decoder button.

I'm Sofia. I run holiday camps for mixed-age groups. My camps are short, so every idea becomes a game or a challenge. Code Breakers is three mornings for 20 campers aged 8 to 12. This is my end project for the Web Foundations module.

My camp, campers and colleague are made up, like me. The site, the codes and the WAVE fixes are real.

1. The live site

Live link tk-learning-artifacts.github.io/skillforge-persona-projects/web-foundations/sofia/site/

It is published free with GitHub Pages, from the same repository as this page. Open it on your phone. Then try the three pages here:

  • HQ
    The camp home. Three mission cards and the agent rules.
  • Caesar wheel
    The JavaScript feature. Turn the wheel, hide a message, crack three notes.
  • Morse lab
    Type a word and watch the lamp flash it, with a beep if you like.

How it meets the brief

  • At least 2 linked pages. There are 3. The same nav bar sits at the top of each page. The current page is marked with aria-current="page", so it shows dark and screen readers say "current page".
  • A flexbox layout that works on phones. The header, the mission cards, the letter strip and the Morse chart all use display: flex with flex-wrap: wrap. Each mission card has flex: 1 1 240px. On a laptop the three cards share a row. On a 360 px phone there is room for one, so they stack. I needed no media query, because wrapping does the work.
  • 1 JavaScript feature. The Caesar wheel. It uses querySelector to find the box and buttons, and addEventListener for clicks and typing. It writes the answer with textContent. It also draws the wheel in SVG and turns the inner ring. The Morse lamp is a bonus.

Why this editor, and who publishes

I first planned to use CodePen. Then I read its terms of service. They say its services are not for anyone under 18. So campers use the Raspberry Pi Code Editor. It runs in the browser and needs no account. It also runs JavaScript in HTML projects, and has an Add file button for a .js file.

GitHub accounts are for ages 13 and up. Most of my campers are younger, so I publish the site, and they don't publish anything. Their pages stay in the editor and in a download.

What I fixed, and who it helps

  1. Language missing (2). I added lang="en" to the html tag. A screen reader now reads the page in an English voice.
  2. Linked image missing alternative text (2). The logo was a picture link with no words. Now the link holds the words "Code Breakers HQ", and the icon is hidden from screen readers. A blind camper hears where the link goes.
  3. Missing alternative text (3). The mission badges had no alt. They only repeat the card title, so they now have an empty alt="". Screen readers skip them instead of reading a file name.
  4. Empty link (1). A bare arrow linked to the Caesar page. Each card now ends with a link in words: "Open the Caesar wheel". Keyboard users can tell where each link goes.
  5. Empty heading (1). Mission 3 had a blank heading I forgot to fill. It now says "Build your agent page".
  6. Missing form label (3). The message box had no label. The Hide and Reveal radio buttons had words beside them, but not tied to them. Now each has a label, and the radios sit in a fieldset with the legend "I want to". Bonus: tapping the word now picks the radio. Small fingers love that.
  7. Empty button (2). The shift buttons held only an icon. Now they show − and +, with aria-label "Shift down by one" and "Shift up by one".
  8. Very low contrast (7). My yellow stamps were 1.59 to 1 on white. WAVE wants at least 4.5 to 1 for normal text. They are red now, at 7.19 to 1. The grey footer, tip and result text were about 2.1 to 1. They now use dark ink. The dark mode colours pass too.

Keyboard-only test

  • The first Tab shows a "Skip to" link. Enter jumps past the nav.
  • Every link and button shows a thick red outline when it has focus.
  • On the wheel: Tab to − and +, then Space. The arrow keys move between Hide and Reveal.
  • The "Show the answer" boxes open with Enter.
  • In the Morse lab, Stop is one Tab after Flash it, so you can stop the lamp fast.

3. Starter project and task card

Mission 3 at camp: every pair finishes a half-made agent page. It has 3 TODOs, one per language. When all 3 are done, the page shows a list of gadgets and a row of badges. A Decode button cracks a secret message.

  • The starter
    The 3 files with copy buttons, how campers load them, my 90-minute plan and the answer key.
  • Run the starter
    See it as campers first see it: badges in a column and a message nobody can read.
  • The task card
    One A4 page. Rookie and Agent hints for each TODO, a bug checklist and Mastermind challenges.

Mixed ages are the hard part of camp. An 8-year-old and a 12-year-old sit at the same laptop. So the card has the same 3 TODOs for everyone, with two kinds of hint. Rookie hints give the exact code. Agent hints name the idea. Mastermind challenges are for the pair who finishes in 10 minutes and starts to wander.

Rubric check

  • Site works on phone and laptop. Checked at 360 px and 1200 px wide, in light and dark mode. Nothing scrolls sideways. Buttons are at least 44 px.
  • Uses semantic HTML throughout. header, nav, main, section, aside and footer on every page. Missions are a list. Inputs have labels. The radios have a fieldset. The answers use details and summary.
  • No WAVE errors left. 0 errors and 0 contrast errors on all 3 pages, by WAVE's rules. Run WAVE on the live links to confirm.
  • Starter tasks fit your students' level. Three short TODOs, Rookie and Agent hints, and Mastermind challenges for early finishers. My colleague's test changed two hints.

What I'd change

Campers can't publish their own pages. GitHub needs them to be 13, and a Raspberry Pi account needs a parent's permission under 13. So the "publish it" part of the brief is mine, not theirs. At the showcase, their pages run from downloads. I'd love a safe way for an 8-year-old to share a live link with their family.

The site also asks a lot of reading for an 8-year-old. Next camp I'd add picture steps to the missions. And the wheel's result box announces every letter you type to a screen reader. That gets chatty. I'd announce it only when you pause.
