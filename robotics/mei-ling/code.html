Who changes what

My P5 pupils don't type this program. I flash it for them. They change only the four numbers at the top, one at a time, and test. That is the whole tuning job, and it fits a club session.

  • STOP_CM: how close is "too close".
  • SPEED: how fast Kotak drives. 0 stops it, 25 is about full speed.
  • BACK_MS: how long it backs away, in thousandths of a second.
  • TURN_MS: how long it turns.

The next two, LEFT_STOP and RIGHT_STOP, come from the trim test. Only the teacher changes them, because a wrong one makes a wheel spin when it should stand still.

The whole program

# Kotak, the shy cardboard robot. Version 3 (final).
# Mei Ling's P5 coding club. micro:bit V2, MicroPython.
#
# It drives forward. When something is close, it stops, backs away,
# turns a random way, and carries on.
# Press A to start. Press B to stop.

from microbit import *
import machine
import utime
import random

# ---- Pupils may change these ----
STOP_CM = 15      # stop when something is this close (cm)
SPEED = 15        # how fast: 0 is stopped, 25 is about full speed
BACK_MS = 300     # how long to back away (ms)
TURN_MS = 500     # how long to turn (ms)

# ---- Only the teacher changes these ----
LEFT_STOP = 78    # servo value where the left wheel stands still
RIGHT_STOP = 75   # servo value where the right wheel stands still
FAR = 400         # what we use when no echo comes back (cm)

TRIG = pin1       # sensor trigger
ECHO = pin2       # sensor echo
LEFT = pin8       # left servo signal
RIGHT = pin16     # right servo signal

# Servos want a pulse every 20 ms.
LEFT.set_analog_period(20)
RIGHT.set_analog_period(20)


def wheels(left, right):
    # Plus is forward for each wheel. The right servo faces the other way,
    # so its number goes down to go forward.
    LEFT.write_analog(LEFT_STOP + left)
    RIGHT.write_analog(RIGHT_STOP - right)


def ping():
    # One shout. Returns cm, or -1 if no echo came back in 30 ms.
    TRIG.write_digital(1)
    utime.sleep_us(10)
    TRIG.write_digital(0)
    t = machine.time_pulse_us(ECHO, 1, 30000)
    if t < 0:
        return -1
    return t / 58


def distance():
    # Shout three times. Ignore the shouts with no echo.
    # Take the middle answer of the ones left.
    heard = []
    for i in range(3):
        d = ping()
        if d >= 0:
            heard.append(d)
        sleep(60)
    if len(heard) == 0:
        return FAR
    heard.sort()
    return heard[(len(heard) - 1) // 2]


# ---- Main program ----
wheels(0, 0)
display.show(Image.ASLEEP)
while not button_a.was_pressed():
    sleep(20)

while not button_b.was_pressed():
    d = distance()                      # sense
    if d > STOP_CM:                     # decide
        display.show(Image.HAPPY)
        wheels(SPEED, SPEED)            # act: carry on
    else:
        display.show(Image.SURPRISED)
        wheels(0, 0)                    # act: stop,
        sleep(200)
        wheels(-SPEED, -SPEED)          # back away,
        sleep(BACK_MS)
        turn = random.choice([-1, 1])   # and turn left or right
        wheels(SPEED * turn, -SPEED * turn)
        sleep(TURN_MS)

wheels(0, 0)
display.show(Image.ASLEEP)

How it works, in club words

Sense: ping and distance

ping makes the sensor shout once, a sound too high for us to hear. Then it times how long the echo pin stays on. Divide the microseconds by 58 and you get centimetres. If no echo comes back within 30 ms, it gives -1.

distance shouts three times. It drops the shouts with no echo, sorts the rest, and takes the middle one. If only two came back, it takes the closer one, to be safe. If none came back, the way is clear: 400 cm.

In club we act this out. Three pupils call out a distance. One calls a silly number. The robot pupil takes the middle one.

Decide: one if

Is the distance more than STOP_CM? Carry on. If not, avoid. The sensor only gives numbers. The if makes the choice.

Act: wheels

wheels(left, right) takes two speeds. Plus is forward. The right servo is mounted facing the other way, so for it, forward means a smaller number. The function hides that, so the main program reads like plain steps: stop, back away, turn.

The face

Happy while driving, surprised when it stops, asleep before A and after B. Pupils can tell what Kotak "thinks" from across the room. It also helps when something is wrong: a surprised face with nothing in front means a wild reading.

Things that catch teachers out

  • Use a sensor that runs on 3 V, like the RCWL-1601. A classic HC-SR04 needs 5 V, and its 5 V echo can damage a micro:bit pin.
  • time_pulse_us waits up to 1 second by default. Give it 30 ms, or one missed echo freezes the robot for a second.
  • It returns a negative number when it times out. Check for that before you divide. Version 1 didn't, and turned at nothing.
  • Servos want a pulse every 20 ms, so set the period to 20 first. Then 77 out of 1023 is about 1.5 ms: stop.
  • Only 3 pins can do PWM at once on the micro:bit. Kotak uses 2, one per servo.
