The sentinel

A micro:bit in a cardboard hood. It sits on a cupboard and logs the light level every minute for 4 hours. Three versions, two failed tests, one that works.

Parts, per room

  • 1 micro:bit V2. The data logging blocks and the speaker need V2.
  • 1 battery pack for 2 AAA batteries, with batteries.
  • 1 cardboard tube, about 10 cm long, with a slot cut for the micro:bit.
  • Blu-tack, and a label with the room and "Please don't move me".
  • We made 9: one per room and a spare.

Safety. A teacher cuts the slots with a craft knife on a cutting mat. Students use scissors only. A teacher puts each sentinel on top of the cupboard. Nobody stands on chairs or tables. Nothing is wired to the room's power, and nobody opens a switchboard or touches anything but the wall switches.

Where it goes

The hood points the LED screen up at the light fitting. Daylight from the side mostly hits cardboard. The micro:bit reads light with some of its LEDs, so the screen must stay dark while it logs.

The code (MakeCode, JavaScript view)

Add the datalogger extension first. The micro:bit has no clock. So the log counts minutes from when the last one out presses A.

// Power Down Cup sentinel, version 3
let threshold = 45     // set from your calibration day
let silent = true      // true in baseline weeks, false in cup weeks
let started = false
let minute = 0

datalogger.includeTimestamp(FlashLogTimeStampFormat.None)
datalogger.setColumnTitles("minute", "light", "lightsOn")
input.lightLevel()     // the first reading is always 0, so throw it away

input.onButtonPressed(Button.A, function () {
    if (started) {
        return
    }
    started = true
    let now = input.lightLevel()
    if (!silent && now > threshold) {
        basic.showIcon(IconNames.No)       // lights still on
        music.playTone(880, music.beat(BeatFraction.Whole))
    } else {
        basic.showIcon(IconNames.Yes)
    }
    basic.pause(2000)
    basic.clearScreen()  // a lit screen would spoil the readings
})

datalogger.onLogFull(function () {
    basic.showIcon(IconNames.Sad)
})

loops.everyInterval(60000, function () {
    if (!started || minute >= 240) {
        return
    }
    minute += 1
    let light = input.lightLevel()
    datalogger.log(
        datalogger.createCV("minute", minute),
        datalogger.createCV("light", light),
        datalogger.createCV("lightsOn", light > threshold ? 1 : 0)
    )
})

Next morning, a CCA member plugs the micro:bit into a laptop. The MY_DATA file on the MICROBIT drive opens in a browser and exports the table. They add up the lightsOn column, then press reset for the next day. Flashing new code hides the old log, so copy the data first.

Calibrate it: find the threshold

This is the test we ran in session 2, as a simulation. One afternoon, 2 pm to 6 pm. The green bands show when the lights were really on. That was 70 minutes after class, and 15 minutes when the cleaner came. That is 85 minutes. Move the threshold. Orange marks show minutes the sentinel gets wrong.

The readings are made up but follow the same pattern as our tests. Your rooms will have their own numbers. That is why you calibrate each one.

Challenge. With the hood off, find one threshold that works on both the sunny and the cloudy day. Then turn the hood on and try again.

Three versions

Version 1: no hood, threshold 100

Logged from power-on, every minute. Two rooms, three days. A CCA member sat in each room for the first hour and wrote down when the lights were really on.

  • Test note 1. In 3A, by the window, a sunny afternoon counted as lights on for nearly 3 hours. The lights were off after 1:10.
  • Test note 2. On a cloudy day, threshold 100 missed the lights completely in 3C.
  • Test note 3. Logging from power-on meant working out when school ended for each room. We got it wrong twice.

Version 2: hood, button A, threshold set per room

  • From notes 1 and 2: the cardboard hood. Daylight now moves the reading a little, and the lights move it a lot.
  • From note 3: someone presses A as the last one out. Minute 1 is when the room is empty. In the baseline weeks it's the CCA member in that class. In the cup, it's the power captain.
  • Each room got its own threshold. We read it with the lights on, then off, on one cloudy and one sunny day. We picked a number in the middle.
  • New problem: in a two-week trial in 4 rooms, we forgot to press A on 6 of 40 days. Those days are lost.

Version 3: the nudge

  • From the forgotten presses: pressing A now gives feedback. A tick if the lights are off. A cross and a beep if not.
  • Captains liked the tick. Forgotten presses fell to 1 of 80 days in the cup weeks. That day, the 3 pm patrol pressed A, and we added the 60 minutes it missed as "lights on". That is the worst case.
  • The catch: the beep is part of the treatment. So in the baseline weeks, silent stays true.
