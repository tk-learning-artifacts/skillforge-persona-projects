What I took out

  • Voting. The +1 button beeps but nothing happens. The vote function has a TODO where the state update was.
  • Sorting the leaderboard. The reveal shows games in file order.
  • One small gap: the key on each GameCard. React warns about it in the console the moment the starter runs.

I kept takeBack whole. It sits right under vote and does the opposite. That is the pattern students need, so TODO 2 becomes read, copy and change, not a blank line. It also follows the Predict, Run, Investigate, Modify, Make steps that the module's starter guide uses.

function vote(id) {
  if (tokensLeft === 0 || !canVote) return
  // TODO 2 (finish the idea): add 1 to this game's votes in myVotes.
  // takeBack, just below, takes 1 away. Copy its pattern.
  beep('vote', sound)
}

function takeBack(id) {
  if (!myVotes[id]) return
  setMyVotes({ ...myVotes, [id]: myVotes[id] - 1 })
  beep('back', sound)
}

The beep stays in on purpose. A button that makes a sound but changes nothing tells a player "your click arrived, the game ignored it". Students hear the bug before they read the code.

Task card: finish the vote board

Goal: a vote board where each player spends 3 tokens, and the reveal puts the winner on top.

Work in pairs. One drives, one navigates. Swap at every step.

Step 0. Predict, then run

Open the starter in React Pad. Before you touch anything, read App.jsx and write down two guesses. What happens when you press +1? What does the console say? Now look. Were you right?

Step 1. TODO 1 Fill the gap

Open GameList.jsx. Give each GameCard a key. Test: press Clear on the console, then Run. The red warning should be gone.

Hint 1

Each game in games.json has an id that never changes. Write key={game.id} on the GameCard.

Step 2. TODO 2 Finish the idea

Open App.jsx and find vote. Make it add 1 to this game's votes. Test: spend all 3 tokens. The coins should go dim and +1 should stop working.

Hint 2

Copy the setMyVotes line from takeBack. Change the minus to a plus. If the game has no votes yet, myVotes[id] is undefined, so use (myVotes[id] || 0) + 1.

Step 3. Make it yours

Open games.json. Change two games to games from your class, with a title, team, genre, colour and a one-line pitch. Keep each id different. Test: vote for your game.

Hint 3

Copy a whole game, from { to }, with the comma after it. If the board shows an error about JSON, look for a missing comma or quote.

Stretch. TODO 3 Make it new

Open Leaderboard.jsx. Sort the games so the most votes come first. Test: vote as 2 players, then reveal.

Hint for the stretch

[...games] makes a copy. sort((a, b) => ...) puts b first when your function returns a number above 0. Votes are in tally[game.id].

Done? Press Download to keep a copy. Then swap devices with another pair and vote on their board.

Tested on a colleague

I gave the starter and card to a colleague for 10 minutes and said nothing, as the module's starter guide suggests. Like the class on the main page, this colleague is made up.

  • Step 0: she guessed +1 would add a star. It beeped and did nothing, and she laughed. Good.
  • TODO 1 took 1 minute. The warning names GameList, so she went straight there.
  • TODO 2 took 4 minutes. Her first try was myVotes[id] + 1. The board said "NaN of 3 tokens left", because undefined + 1 is NaN. I added the || 0 part to hint 2.
  • Step 3 took 3 minutes. She broke the JSON once and the error screen caught it. That is the effect's error handling doing its job.
  • She didn't reach the stretch. That's right for a stretch.
