Answers for teachers

I checked each answer in Python 3.13. I used the copy of the file from 24 October 2026.

P1
"1982", as text. [:4] takes the first four characters of a string. The csv module gives every value as text.
P2
Three lines, one per year in the list. The middle number is 12 on each, the number of months.
P3
The program prints 1984 12 26.77, 2004 12 27.86 and 2024 12 28.44. 2024 is 1.67 °C warmer than 1984. Collect guesses before anyone runs it. 1984 was the coolest year at Changi Airport. So this gap is bigger than the trend suggests. That is worth a talk: picking the end points changes the story.
I1
TypeError: unsupported operand type(s) for +: 'int' and 'str'. The traceback shows line 17, then line 5, inside mean(). The mistake is on line 14, but nothing goes wrong until sum() tries to add text. Errors show where data is used, not where it went wrong.
I2
2026 9 28.56. It has only 9 months, January to September. It leaves out November and December, which are cooler. So its mean looks warmer than a full year would be. Don't compare it.
I3
KeyError: 1984, from line 17. The keys are text, because line 11 slices a string. 1984 the number is not the same key as "1984" the text.

Make (one example)

May is warmest, at 28.55 °C. January is coolest, at 26.70 °C.

import csv

names = ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
         "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
by_month = {}
with open("changi_monthly_mean_temp.csv") as f:
    for row in csv.DictReader(f):
        year = int(row["month"][:4])
        month = int(row["month"][5:])
        if year >= 1984 and year <= 2025:
            if month not in by_month:
                by_month[month] = []
            by_month[month].append(float(row["mean_temp"]))

for month in range(1, 13):
    temps = by_month[month]
    print(names[month - 1], f"{sum(temps) / len(temps):.2f}")
