Problem set

The ladder

Twelve USACO problems, three a week, each rung a little higher. Every one has two hint cards: a Nudge and a Push.

A Nudge points you at what to look at. A Push names the idea. Neither one is code. Flip the Nudge after 10 minutes stuck, and the Push 5 minutes after that.

The level tags come from the USACO Guide, which rates each practice problem in a module. The ones I used run from Easy to Medium. Two of mine are not in the Guide's tables, so they say "not rated". The colour bar on the left shows the same thing: green for Bronze Easy, yellow for Bronze Medium, orange for Silver, and plain for the unrated Bronze one.

How the ladder climbs: Bronze Easy for seven rungs, then Bronze Medium, then Silver. Rung 10 steps back to Bronze on purpose. BFS is new that week, so it starts on a 10 by 10 grid before the 1,000 by 1,000 one.

Older problems, up to 2019 here, read from a file such as lostcow.in and write to lostcow.out. Daisy Chains, from December 2020, uses the keyboard and screen. The tags say which.

Week 1: Simulate it

1The Lost Cow

  • Bronze · Easy
  • 2017 US Open
  • simulation
  • file input

Farmer John zigzags along a line, doubling each turn, until he finds Bessie. How far does he walk?

Nudge

Act it out on a number line with x = 3 and y = 6. Write down every turning point.

Push

Keep where he is now and where the next turn is. Before each leg, check if Bessie lies between them.

2Speeding Ticket

  • Bronze · Easy
  • 2015 December
  • simulation, lists
  • file input

The road has speed limits in segments, and Bessie drove in segments. By how much did she go over?

Nudge

The road is exactly 100 miles. What if you knew the limit and her speed at every single mile?

Push

Build two lists of 100 numbers, one entry per mile. Then compare them mile by mile.

3The Bucket List

  • Bronze · Easy
  • 2018 December
  • simulation
  • file input
  • week 1 sprint

Cows need buckets while they are milked. How many buckets must Farmer John own?

Nudge

Times only go up to 1,000. Could you look at every single moment?

Push

Returned buckets get used again. So what matters is the moment when the most buckets are out at once.

Week 2: Try everything

4Milk Pails

  • Bronze · Easy
  • 2016 February
  • complete search
  • file input

Pour small and medium pails into a big one without spilling. What is the most milk you can add?

Nudge

M is at most 1,000. How many small pails could you possibly pour?

Push

One loop for the number of small pails, one for medium. Keep the best total that still fits.

5Diamond Collector

  • Bronze · Easy
  • 2016 US Open
  • complete search
  • file input

Put as many diamonds as you can in a case, as long as no two differ in size by more than K.

Nudge

In the best case, one diamond is the smallest. You do not know which, so try each one.

Push

Once you fix the smallest size, which other diamonds can join it? Count them.

6Daisy Chains

  • Bronze · Easy
  • 2020 December
  • complete search
  • keyboard input
  • week 2 sprint

For every run of flowers in a row, is there a flower with exactly the average number of petals?

Nudge

N is at most 100. How many runs of flowers are there? Small enough to check every one?

Push

An average can only match a flower if it is a whole number. Check that first, then look for it in the run.

Week 3: Sort and search

7Where Am I?

  • Bronze · Easy
  • 2019 December
  • sets, strings
  • file input

Find the smallest K so that every K mailboxes in a row look different from every other K in a row.

Nudge

Try K = 1, then 2, then 3. The first K that works is the answer.

Push

For one K, put every piece of length K into a set. If a piece is already there, that K fails.

8Why Did the Cow Cross the Road III

  • Bronze · Medium
  • 2017 February
  • sorting, simulation
  • file input

Cows queue at one gate for questioning. When is the last cow through?

Nudge

Read the input section again. Does it promise the cows arrive in order?

Push

Keep one number: when the gate is next free. Each cow starts at the later of that time and when she arrives.

9Counting Haybales

  • Silver · not rated
  • 2016 December
  • sorting, binary search
  • file input
  • week 3 sprint

100,000 haybales and 100,000 questions: how many bales lie between A and B?

Nudge

Checking every bale for every question is 100,000 times 100,000. Is that inside the time limit?

Push

Sort the bales once. Then, for each question, find where A and B would sit in the sorted list.

Week 4: Flood the grid

10Bucket Brigade

  • Bronze · not rated
  • 2019 US Open
  • BFS, shortest path
  • file input

Cows pass buckets from a lake to a burning barn, around a rock. How few cows can do it?

Nudge

The cows form a path. You want the shortest path from lake to barn that misses the rock.

Push

A BFS from the lake gives the steps to every square. Which squares on the path hold cows?

11Icy Perimeter

  • Silver · Easy
  • 2019 January
  • flood fill
  • file input

Find the biggest blob of ice cream in a grid up to 1,000 by 1,000, and its perimeter.

Nudge

Find each blob with a flood fill. Count its cells as you go.

Push

Each cell has 4 sides. A side counts for the perimeter when the next cell is not ice, or is off the grid.

12Mooyo Mooyo

  • Silver · Medium
  • 2018 December
  • flood fill, simulation
  • file input
  • week 4 sprint

Groups of K or more same-coloured haybales vanish, the rest fall, and it repeats. Print the final board.

Nudge

Split it into two jobs. One clears big regions. The other drops the haybales. Repeat until nothing clears.

Push

Gravity works one column at a time. Keep the non-zero cells in order and stack them at the bottom.
