The problem set

Twelve Kattis problems, easiest first. Each has a hint ladder of three steps and my own Python solution.

How the hints work. Hint 1 points you at the right part of the problem. Hint 2 names the idea. Hint 3 tells you where people trip. None of them is code. Open them in order, and only after 10 minutes of trying.

My solution sits below the hints, closed. Open it after you have an Accepted, or after you have used all three hints and a full session.

The difficulty is Kattis's own number, read on 24 October 2026. It changes a little over time. Time limits are per test file.

Week 1 // judges and verdicts

01 Quadrant Selection

  • Kattis 1.2
  • 1 s
  • if and elif
  • O(1)

Read a point and say which quadrant it is in. The skill is reading input exactly as the statement lays it out.

Hint 1

Look at the input section again. How many lines does it have, and what is on each?

Hint 2

Draw the two axes on paper. Write the sign of x and the sign of y in each of the four quadrants.

Hint 3

Neither number is ever 0. So every point is in exactly one quadrant, and your branches should cover all four.

My solution
x = int(input())
y = int(input())

if x > 0 and y > 0:
    print(1)
elif x < 0 and y > 0:
    print(2)
elif x < 0 and y < 0:
    print(3)
else:
    print(4)

Checked on both Kattis samples.

02 R2

  • Kattis 1.3
  • 1 s
  • rearranging a formula
  • O(1)

You know one number and the mean of two. Find the other. Two numbers arrive on one line this time.

Hint 1

Write the formula for the mean on paper. Which letters do you know?

Hint 2

Get rid of the "divide by 2" first. What do you multiply both sides by?

Hint 3

The numbers can be negative. Check that your answer is a whole number, with no ".0" at the end.

My solution
# S = (R1 + R2) / 2, so R2 = 2S - R1.
r1, s = map(int, input().split())
print(2 * s - r1)

Checked on both Kattis samples.

03 Spavanac

  • Kattis 1.3
  • 1 s
  • modulo, time
  • O(1)

Set an alarm 45 minutes earlier on a 24-hour clock. The first problem where an edge case decides the verdict.

Hint 1

Work out the answer for 0 10 by hand. Does your code give the same?

Hint 2

Hours and minutes are awkward to subtract. Is there one number that describes the time instead?

Hint 3

Try -35 % 1440 in Python. What does % do with a negative number, and how could that help?

My solution
h, m = map(int, input().split())

# Work in minutes since midnight. The % wraps 0:10 back to 23:25.
minutes = (h * 60 + m - 45) % (24 * 60)
print(minutes // 60, minutes % 60)

Checked on the 3 Kattis samples, and on all 1,440 times of day against Python's datetime module.

Week 2 // sets, sorting and Big O

04 No Duplicates

  • Kattis 1.4
  • 1 s
  • set
  • O(n)

Does any word in a line repeat? A first look at what a set is for.

Hint 1

split() turns the line into a list of words. Print it and look.

Hint 2

What does a set do when you give it the same word twice?

Hint 3

You can answer this by comparing two lengths. No loop needed.

My solution
words = input().split()

# A set keeps one copy of each word. Fewer items means a repeat.
if len(set(words)) == len(words):
    print("yes")
else:
    print("no")

Checked on the 3 Kattis samples. A set lookup takes about the same time however big the set is, so this is O(n) in the number of words.

05 Secure Doors

  • Kattis 1.6
  • 1 s
  • set, state
  • O(n)

Read an access log and flag anyone who enters twice or leaves without entering.

Hint 1

At any moment, what is the one thing you need to remember?

Hint 2

Which structure answers "is this name in here?" quickly, and lets you add and remove names?

Hint 3

Read the second paragraph again. After an anomaly, is the person inside or outside?

My solution
n = int(input())
inside = set()

for _ in range(n):
    action, name = input().split()
    if action == "entry":
        note = " (ANOMALY)" if name in inside else ""
        inside.add(name)
        print(name + " entered" + note)
    else:
        note = "" if name in inside else " (ANOMALY)"
        inside.discard(name)
        print(name + " exited" + note)

Checked on the Kattis sample. discard does nothing if the name is missing, where remove would crash.

06 Shopaholic

  • Kattis 1.6
  • 2 s
  • sorting, greedy
  • O(n log n)

Buy 3, pay for 2, and the cheapest is free. Group the items for the biggest discount. Up to 200,000 prices.

Hint 1

Work through the example in the statement. Which items would you like to see in the same group?

Hint 2

Sort the prices. Then think about which order, dearest first or cheapest first, makes the groups easy.

Hint 3

200,000 numbers on one line. Reading with sys.stdin.read() is safe. A loop inside a loop is not.

My solution
import sys

data = sys.stdin.read().split()
n = int(data[0])
prices = sorted(map(int, data[1:n + 1]), reverse=True)

# Group the dearest three, then the next three, and so on.
# The cheapest of each group is free: positions 2, 5, 8, ...
print(sum(prices[2::3]))

Checked on the Kattis sample, and against a slow version that tries every way to group up to 7 items, on 60 random cases. 200,000 prices take well under a second.

Week 3 // brute force, recursion, binary search

07 Tri

  • Kattis 1.7
  • 1 s
  • brute force
  • O(1)

Put back the = sign and one operation between three numbers. Small enough to try everything.

Hint 1

The numbers stay in order. How many places can the = sign go?

Hint 2

Count the cases: places for = times operations. Is that a small number?

Hint 3

Division needs care. How can you test "a divided by b is c" without dividing?

My solution
a, b, c = map(int, input().split())

# Try every place for the = sign and every operation.
# Division is checked with multiplication, so 15/3 never becomes 5.0.
# a = b * c is the same test as a / b = c, so it needs no line of its own.
if a + b == c:
    print(f"{a}+{b}={c}")
elif a - b == c:
    print(f"{a}-{b}={c}")
elif a * b == c:
    print(f"{a}*{b}={c}")
elif a == b * c:
    print(f"{a}/{b}={c}")
elif a == b + c:
    print(f"{a}={b}+{c}")
elif a == b - c:
    print(f"{a}={b}-{c}")
else:
    print(f"{a}={b}/{c}")

Checked on both Kattis samples, and on 150 random solvable triples: every output was a true equation with the numbers in order.

08 Perket

  • Kattis 1.7
  • 1 s
  • recursion, subsets
  • O(2N)

Choose ingredients so sourness and bitterness are as close as possible. Up to 10 ingredients.

Hint 1

N is at most 10. How many different groups of ingredients are there?

Hint 2

Each ingredient is in or out. A function can decide for one ingredient, then call itself for the next.

Hint 3

Read the last line of the statement. One of your groups is not allowed.

My solution
n = int(input())
items = [tuple(map(int, input().split())) for _ in range(n)]

best = float("inf")


def choose(i, sour, bitter, used):
    """Decide for item i: leave it out, or put it in."""
    global best
    if i == n:
        if used > 0:
            best = min(best, abs(sour - bitter))
        return
    choose(i + 1, sour, bitter, used)
    s, b = items[i]
    choose(i + 1, sour * s, bitter + b, used + 1)


# 2 choices for each of at most 10 items: 2**10 = 1024 meals.
choose(0, 1, 0, 0)
print(best)

Checked on the 3 Kattis samples, and against itertools.combinations on 60 random cases. The recursion is only 11 calls deep.

09 Guess the Number

  • Kattis 1.9
  • 1 s
  • binary search, interactive
  • O(log n)

Find a number from 1 to 1,000 in 10 guesses, with "lower" or "higher" after each. Your program talks to the judge.

Hint 1

Play it with a partner first. What first guess leaves the fewest numbers in the worst case?

Hint 2

Keep two numbers: the lowest and highest the secret could still be. Each reply moves one of them.

Hint 3

The judge cannot reply until it sees your guess. Look up the flush argument of print.

My solution
low, high = 1, 1000

while True:
    mid = (low + high) // 2
    print(mid, flush=True)  # the judge waits for this line
    reply = input().strip()
    if reply == "correct":
        break
    elif reply == "lower":
        high = mid - 1
    else:
        low = mid + 1

Kattis has no sample file for this one. I wrote a small judge and ran all 1,000 secrets. The most guesses needed was 10.

Week 4 // grids and BFS

10 Knight Jump

  • Kattis 1.9
  • 1 s
  • BFS, shortest path
  • O(N2)

The fewest knight moves to the corner of a board with blocked cells, or -1.

Hint 1

Every move costs one step. Which search reaches cells in order of their distance?

Hint 2

Use collections.deque as the queue. Record a cell's step count the moment you add it.

Hint 3

What happens to your code when the corner is never reached? Look at sample 2.

My solution
from collections import deque

n = int(input())
board = [input() for _ in range(n)]

for r in range(n):
    for c in range(n):
        if board[r][c] == "K":
            start = (r, c)

moves = [(2, 1), (2, -1), (-2, 1), (-2, -1),
         (1, 2), (1, -2), (-1, 2), (-1, -2)]

steps = {start: 0}
queue = deque([start])
while queue:
    r, c = queue.popleft()
    for dr, dc in moves:
        nr, nc = r + dr, c + dc
        if 0 <= nr < n and 0 <= nc < n and board[nr][nc] != "#" \
                and (nr, nc) not in steps:
            steps[(nr, nc)] = steps[(r, c)] + 1
            queue.append((nr, nc))

# Cell (1, 1) in the statement is (0, 0) here.
print(steps.get((0, 0), -1))

Checked on both Kattis samples. An empty 100 by 100 board takes 0.04 seconds.

11 Counting Stars

  • Kattis 2.2
  • 1 s
  • flood fill
  • O(m × n)

Count the stars in each image. A star is a group of touching white pixels. Up to 50 images in one input.

Hint 1

Scan the image row by row. When does a white pixel mean a new star?

Hint 2

Before you scan on, visit every pixel of that star and mark it. Then you can never count it twice.

Hint 3

How many images are in the sample? How does your program know when the input ends?

My solution
import sys
from collections import deque

lines = sys.stdin.read().split("\n")
pos = 0
case = 0

while pos < len(lines) and lines[pos].strip():
    m, n = map(int, lines[pos].split())
    sky = [list(lines[pos + 1 + i].strip()) for i in range(m)]
    pos += m + 1
    case += 1

    stars = 0
    for r in range(m):
        for c in range(n):
            if sky[r][c] != "-":
                continue
            # A new star. Flood it so we never count it again.
            stars += 1
            sky[r][c] = "#"
            queue = deque([(r, c)])
            while queue:
                y, x = queue.popleft()
                for ny, nx in ((y + 1, x), (y - 1, x), (y, x + 1), (y, x - 1)):
                    if 0 <= ny < m and 0 <= nx < n and sky[ny][nx] == "-":
                        sky[ny][nx] = "#"
                        queue.append((ny, nx))
    print(f"Case {case}: {stars}")

Checked on the Kattis sample. 50 random 100 by 100 images take about a quarter of a second. I used BFS, not recursion: a recursive flood fill on a big star can pass Python's recursion limit.

12 Grid

  • Kattis 2.3
  • 1 s
  • BFS, speed
  • O(n × m)

Each square says how far you must jump. Find the fewest jumps from corner to corner, on a grid up to 500 by 500.

Hint 1

A jump of k squares is still one move. Does that change which search you use?

Hint 2

What can you do from a square with 0 on it?

Hint 3

500 by 500 is 250,000 squares, and the limit is 1 second. How fast is your "have I been here?" check?

My solution
import sys
from collections import deque

data = sys.stdin.read().split()
n, m = int(data[0]), int(data[1])
digits = [int(ch) for row in data[2:2 + n] for ch in row]

# One flat list: cell (r, c) is index r * m + c. It is faster than
# a dict of tuples, and 500 x 500 = 250,000 cells need the speed.
dist = [-1] * (n * m)
dist[0] = 0
queue = deque([0])
while queue:
    cell = queue.popleft()
    r, c = divmod(cell, m)
    k = digits[cell]
    if k == 0:
        continue
    for nr, nc in ((r + k, c), (r - k, c), (r, c + k), (r, c - k)):
        if 0 <= nr < n and 0 <= nc < m:
            nxt = nr * m + nc
            if dist[nxt] == -1:
                dist[nxt] = dist[cell] + 1
                queue.append(nxt)

print(dist[n * m - 1])

Checked on the 3 Kattis samples. A 500 by 500 grid of 1s, the slowest case I could build, took about half a second on my laptop. The judge's machine may be slower, which is why I used a flat list.
