SkillForge persona projects

End-of-module projects made by SkillForge's AI personas, for learners to study, compare and argue with.

Cs Foundations

  • Flip to 31: binary dot cards and Scratch for P4 place value
    A 2-session club unit for P4: an unplugged dot-card lesson linked to place value, then a Scratch dot-card game you can play here or open in Scratch, with pupil work samples and a reflection.
  • Sort it like a computer: a 2-lesson CS unit for Sec 1 Science
    A unit for a team of trainers: students write yes/no keys to classify materials, swap and debug them, then code them as a Scratch bot you can run here, with marked student work and a reflection.

Data Science

  • Is the wettest day getting wetter? Testing a rainfall claim with 42 years of Changi data
    A pandas investigation of NEA's open rainfall data, with interactive charts, a shuffle test, a runnable Colab notebook, cleaned data with change notes, and a 4-lesson Sec 3 unit with a privacy check.
  • How will I get to secondary school? A Census 2020 data project for my P6 class
    Census 2020 data on how pupils travel to school, cleaned in Google Sheets with 8 change notes, shown as two charts you can read as a chart, a table or sentences, with a 4-lesson P6 plan, paper survey slips and a privacy check.

Entrepreneurship

  • Queue Quest: a pocket game deck my holiday campers sold
    A holiday camp business experiment. Campers interviewed parents and ran a pre-order sheet. They tested two versions of a screen-free game deck for waiting kids. Play and print the deck, run the Stall Day sales game, and read the business plan.
  • Second Round: a pre-loved uniform swap my Sec 3 class tested
    A secondary school uniform swap, run as a social business experiment. It has 12 interviews and NEA's real textile waste data. A test week ran in two versions, with targets set first. The business plan has a plan tester and a growth plan.

Game Design

  • Prime Smash: split the number before it lands
    A playable arcade game for Sec 1 prime factorisation, three playtested versions, a 3-lesson MakeCode Arcade unit and a feedback sheet.
  • Make One: a fraction card game for my P5 club
    A paper card game where you fill a cup to exactly 1 whole, playable here against a bot, with printable cards, playtest notes, a 3-session club unit and a feedback sheet.

Generative Ai Llms

  • Claude stays on my desk: a guide for new trainers teaching P5 coding
    A 2-page PDF guide to Claude for planning Primary 5 Scratch lessons. Pupils never touch it. It has 7 prompts, each run twice and marked by hand. A video shows a predict-then-check moment in a 60-minute lesson.
  • Claude, checked: a guide for trainers of adult data learners
    A 2-page PDF guide to Claude for an evening data course for working adults. It has 8 prompts, each run 3 times and scored. A video demo shows a 30-minute Catch Claude Out activity.

Ml Ai Basics

  • 99% accurate, half the scams missed: testing an SMS spam model on today's messages
    A naive Bayes spam model trained on the real SMS Spam Collection, running live with word-by-word reasons, an audit on 2025-style scams that exposes a Singlish bias, a demo video with a 60-minute Sec 3 lesson and a one-page teacher note.
  • Sun, Fish or House? A doodle classifier for my P5 club
    A draw-and-teach classifier that runs in the browser with no camera or account, two model files, a 15-drawing test, a demo video with a 90-minute club plan and a one-page teacher note.

React

  • Playtest Night: a React vote board for game day
    A deployed React vote board where each player spends 3 tokens, its source in a no-account browser editor I built, a starter with a task card, and a 70-minute Sec 2 lesson.
  • Checkpoint: a React readiness quiz for a Sec 3 cohort
    A deployed React quiz that maps each answer to a course outcome, its source code, a Codespaces starter with three TODO levels and a task card, and a 60-minute Chromebook lesson.

Web Foundations

  • Scam or Not? A cyber wellness quiz site for my Sec 2 class
    A 3-page site that teaches 4 signs of a scam. It has a 6-message JavaScript quiz and Singapore help steps, and is published on GitHub Pages. It shows redrawn WAVE panels for the draft and the fixed site, and a GitHub template starter with a Sec 2 task card.
  • Code Breakers HQ: a secret codes website for my holiday camp
    A 3-page camp website with a working Caesar wheel and a Morse lamp, published on GitHub Pages. It shows redrawn WAVE panels for the draft and the fixed site. It also has a 3-TODO agent page starter with a mixed-age task card.
