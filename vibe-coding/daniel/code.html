The shuffle test

ChatGPT's first shuffle was list.sort(() => Math.random() - 0.5). It looks random. This test shuffles a class of 28 students 20,000 times. It counts how often each student lands first in the list. In a fair shuffle, everyone lands first about 1 time in 28, or 3.6%.

Fisher-Yates, the one in the app now

The sort shuffle gives No. 1 far more first places. That's the first student on my register, every single lesson. The numbers change a little each run, because they are random. The pattern doesn't.

These results come from your browser's own sort. javascript.info says the pattern depends on each browser's sort. Another browser may show a different shape.

Things I checked in the code

  • No typed text ever goes through innerHTML. The helper el() only sets text.
  • No global names leak out, except window.FairPicker, which the demo and this page use.
  • Storage errors can't crash the app. Loading and saving sit inside try and catch.
  • Each pure function, like shuffle and makeGroups, takes its random function as an input. That's how the demo picks the same students every time.
