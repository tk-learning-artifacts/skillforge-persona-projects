    Why it's a demo you can pause

    A video file of a screen goes out of date the day you fix a bug. This one runs the code you can use on the project page, so it always matches. It also has captions, and you can jump to any part.

    For my class, I would record the same 90 seconds with the Chromebook's built-in Screen capture tool. Press Shift, Ctrl and the Show windows key, then pick Screen record. The video goes to the Downloads folder.

    The names in the demo are made up. They stay inside this page and are never saved.

    The script

    I wrote the voice-over first, then timed the clicks to it. Each line is one caption.

      How I planned 90 seconds

      • One job per chapter: class list, pick, absent, groups, safety.
      • Show the fixes I made by hand. The groups and the safety test are both my changes.
      • Nothing a viewer has to read fast. Each caption stays up for at least 3 seconds.
      • End on where to go next: the prompt log and the code.
