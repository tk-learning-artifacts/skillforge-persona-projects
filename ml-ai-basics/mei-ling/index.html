Sun, Fish or House?

Draw a doodle. Teach the computer what it is. Then try to fool it.

I'm Mei Ling. I run an after-school coding club for Primary 5 and 6 pupils. My kids love Teachable Machine and the webcam. But our webcams freeze, log-ins fail, and some pupils hate being on camera. So I made this doodle classifier. It needs no camera, no account and no internet once the page has loaded.

It is a real model. You teach it with drawings, it guesses new ones, and it shows how sure it is.

How it works, in club words

What I tell the pupils

The computer can't see a fish. It sees 400 little squares, some dark and some light. When you draw, it looks through every drawing you taught it. It picks the 5 that look most like yours, square by square. Those 5 vote. The most votes wins. The bar shows the votes: 3 votes out of 5 is 60%.

What teachers should know

This is a k-nearest neighbours classifier, with k = 5. It compares raw squares, so it has no idea of "rays" or "fins". Teachable Machine is different. Its FAQ says it uses transfer learning: a big network already trained on many pictures does most of the work, and your classes become the last step. Both learn only from the examples you give.

Four words I want pupils to use by the end:

  • Training data: the drawings you teach it with.
  • Label: the name you give each drawing, like Fish.
  • Features: what it looks at. Here, only which squares are dark.
  • Overfitting: learning your drawings too well, so new ones fool it.

Overfitting, with my own model

Here is how I explain it to P5s. Say you only teach it 3 suns, all drawn by you, all with 8 rays. It does not learn "sun". It learns "Mei Ling's sun with 8 rays". It is like learning one spelling list by heart. You get full marks on that list, then trip on new words.

You can see this in version 1. All 12 suns I taught have rays. So a plain circle looks more like a fish body than a sun. The test below shows it.

The two wrong guesses were 100% sure. That is my favourite moment in the club. "Sure" is not the same as "right".

I guessed the left-facing fish would fail, since every taught fish faces right. It didn't. The body is an oval, and an oval looks the same both ways. My guess was wrong, and the test told me so.

How I improved it

  1. I looked at the wrong ones. Both were shapes my training data never had: a sun with no rays, a house taller than it is wide.
  2. I drew 6 new drawings: 3 tall houses and 3 suns with no rays. I did not use the test drawings. If I teach it the test, the test means nothing.
  3. I ran the same 15 drawings again: 15 of 15. But the two fixed ones only got 60%. It is less sure, and that is fair.

Bias check: who drew it?

Every drawing in my model came from one hand: a small script that draws wobbly lines. So the model knows one drawing style. Things I check with the club, and what we find:

  • Style. A sun drawn as a quarter in the corner of the page, the way some kids draw it, is new to the model. Try it.
  • Detail. Scales, bubbles or a smiley face add dark squares. A busy drawing can drift toward the wrong thing.
  • Size and place. These don't matter. The page cuts out and shrinks every drawing first.
  • People. If only 3 pupils add drawings, the model learns their style. Everyone in the pair should add some.

The same thing happens with Teachable Machine and real photos. If every sample is taken under the same classroom light, the model learns that light. Its FAQ asks makers to think about fairness at every step.

The three deliverables

  • Model file: the trainer above, plus version 1 and version 2 as files. "Open a model file" loads them back.
  • Short demo video: a 60-second video of the demo, with the 90-minute club plan it fits into.
  • Teacher note: one printable page on what it does, what it gets wrong and how to keep it safe.

What it can't do, and what I would change

  • It only knows 3 things. Draw a cat and it still says sun, fish or house. A Teachable Machine model also picks only from your classes. That is why makers often add a "nothing" class.
  • It compares squares, not ideas. A real sun drawn as a yellow blob would fool it, since it can't see colour.
  • My test drawings came from the same script as my training ones. Real pupils' drawings are messier. I'd want a test set drawn by the club next term.
  • Pupils who can't draw with a mouse can tap a test drawing to load it. But they can't teach it new drawings with a keyboard. I haven't solved that yet.
