Task card: finish Hitbox

One page when printed. Pairs share one PC. Swap who types after each quest.

Goal. Finish a word app. Tap a word to open it. Mark it known and a star stays, even when the phone turns.

You get: the hitbox-starter project. It runs, but it is broken in 3 places. Look for // TODO. Android Studio lists them all in View, Tool Windows, TODO.

Step 0: Predict, then run (5 min)

Read WordListScreen.kt. Write down what you think the list will show. Then press Run. Were you right? What is missing?

Quest 1: show the meaning (5 min)

Each row shows only the word. Make it show the meaning under it.

Test: every row has a grey line of text under the word.

Quest 2: open the word (10 min)

Tapping a word does nothing. Make it open the detail screen for that word. The back button should bring you back.

Test: tap "Sprite". The next screen says Sprite at the top.

Boss quest: make stars stick (20 min)

"I knew it" does nothing yet. Add a known state in HitboxApp. Pass it to both screens. Update it when the player answers.

Test: mark 2 words known. The counter says Known 2 of 12. Rotate the phone. Still 2.

Stretch: make it yours

Add 3 words from the game your pair is planning. Or add a "Level 1 only" button that filters the list.

Hints (open one only when stuck)

Hint for Quest 1

Copy the headlineContent line. Change it to supportingContent, and show word.meaning.

Hint for Quest 2

Inside the braces, write navController.navigate(WordDetail(word.id)).

Hint 1 for the boss

Start with var known by rememberSaveable(stateSaver = KnownSaver) { mutableStateOf(emptySet<Int>()) }.

Hint 2 for the boss

Replace both emptySet() and false with known and id in known. To update: known = if (nowKnown) known + id else known - id.

Red error? Read this first

Red text under a word usually means a missing import. Click the word and press Alt+Enter (Option+Return on a Mac). Pick the import.

For the trainer

  • Level: Sec 2 and 3 club members who did the Kotlin tour and the Compose counter. Quest 1 and 2 copy a pattern. The boss quest is the only new idea: hoisting state.
  • Timing: about 40 minutes for the quests. My test run on a club PC took 14 minutes for the open, sync and first run, so the PCs get synced the week before.
  • Check: walk round with the three tests. A pair that passes the boss test can explain why the star survives rotation. Ask them.

The club, the PCs and my timings are made up for this example, like me. The code is real and builds.
