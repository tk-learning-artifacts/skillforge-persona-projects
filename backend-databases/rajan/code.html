Run it on your own computer

  1. Unzip the folder. Open a terminal in it.
  2. Install Flask: pip install flask.
  3. Build the database: python setup_db.py. It asks for a librarian password. Type a made-up one.
  4. Start the server: flask --app app run --debug.
  5. Open http://127.0.0.1:5000. Log in as librarian.
  6. To look inside the database: python -m sqlite3 library.db, then SELECT * FROM loans;.

Debug mode is for your own machine only. Flask's docs warn that its debugger can run any Python code from the browser.

schema.sql

Dates are text in YYYY-MM-DD form. That way, comparing two dates as text gives the right answer. The last line is the part I like most. A unique index with a WHERE clause only counts the rows that match. So a book can have many old loans but only one open one. The database enforces it, not my Python.

schema.sql
-- Tables for the class library. Run by setup_db.py.
DROP TABLE IF EXISTS loans;
DROP TABLE IF EXISTS books;
DROP TABLE IF EXISTS users;

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  username TEXT NOT NULL UNIQUE,      -- a made-up handle, never a real name
  pw_hash TEXT NOT NULL,              -- werkzeug hash, never the password
  is_librarian INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE books (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  author TEXT NOT NULL
);

CREATE TABLE loans (
  id INTEGER PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id),
  book_id INTEGER NOT NULL REFERENCES books(id),
  due_date TEXT NOT NULL,             -- YYYY-MM-DD, so text order is date order
  returned_on TEXT                    -- NULL while the book is out
);

-- A book can be out on only one loan at a time.
-- The database enforces it, so two clicks at once can't both win.
CREATE UNIQUE INDEX one_open_loan ON loans(book_id) WHERE returned_on IS NULL;

setup_db.py: the database setup script

It wipes and rebuilds library.db. The librarian password is typed in, so it is never in the code. The sample readers get random passwords that are never printed. Nobody can log in as them. Their loans are dated from today, so two are always overdue.

setup_db.py
"""Build library.db from schema.sql and fill it with made-up data.

Run it once from a Bash console:  python3 setup_db.py
Running it again wipes the database and starts over.
"""
import getpass
import os
import secrets
import sqlite3
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

from werkzeug.security import generate_password_hash

HERE = os.path.dirname(os.path.abspath(__file__))
DB = os.path.join(HERE, "library.db")
KEY = os.path.join(HERE, "secret.key")

BOOKS = [
    ("Animal Farm", "George Orwell"),
    ("The Hobbit", "J. R. R. Tolkien"),
    ("Holes", "Louis Sachar"),
    ("The Giver", "Lois Lowry"),
    ("Wonder", "R. J. Palacio"),
    ("Frankenstein", "Mary Shelley"),
]

# Made-up readers. Their passwords are random and printed nowhere,
# so nobody can log in as them. They only exist to own sample loans.
READERS = ["reader_kite", "reader_moss", "reader_pebble"]


def sg_today():
    return datetime.now(ZoneInfo("Asia/Singapore")).date()


def main():
    password = getpass.getpass("Choose a password for the librarian account: ")
    if len(password) < 8:
        raise SystemExit("Use at least 8 characters.")

    con = sqlite3.connect(DB)
    with open(os.path.join(HERE, "schema.sql")) as f:
        con.executescript(f.read())

    with con:  # commits at the end of the block
        con.execute(
            "INSERT INTO users (username, pw_hash, is_librarian) VALUES (?, ?, 1)",
            ("librarian", generate_password_hash(password)),
        )
        for name in READERS:
            con.execute(
                "INSERT INTO users (username, pw_hash) VALUES (?, ?)",
                (name, generate_password_hash(secrets.token_urlsafe(16))),
            )
        con.executemany("INSERT INTO books (title, author) VALUES (?, ?)", BOOKS)

        today = sg_today()
        sample_loans = [  # (user_id, book_id, days from today)
            (2, 1, -5),   # overdue
            (3, 3, -1),   # overdue by a day
            (3, 4, 9),    # not due yet
        ]
        for user_id, book_id, days in sample_loans:
            due = (today + timedelta(days=days)).isoformat()
            con.execute(
                "INSERT INTO loans (user_id, book_id, due_date) VALUES (?, ?, ?)",
                (user_id, book_id, due),
            )
    con.close()

    # Flask signs its session cookie with this key. Keep it out of your code.
    with open(KEY, "w") as f:
        f.write(secrets.token_hex())
    print("Made library.db and secret.key. Log in as 'librarian'.")


if __name__ == "__main__":
    main()

app.py: the API

Things to look for:

  • Every value from a request reaches SQL through a ?. The only f-strings add TODAY, a fixed text I wrote.
  • SQLite's 'now' is UTC. Without '+8 hours', a book due today would turn overdue at 8 a.m. in Singapore, not midnight.
  • with db(): commits on success and rolls back on an error. Forgetting to commit is the most common bug I see.
  • Login gives the same message for a wrong username and a wrong password. A different message would tell an attacker which usernames exist.
  • The librarian check happens on the server for every librarian route. The page only hides buttons.
app.py
"""Class library: a small Flask API on SQLite, with logins.

Every query uses ? placeholders. Passwords are stored as werkzeug hashes.
"""
import os
import re
import sqlite3

from flask import Flask, g, request, session
from werkzeug.security import check_password_hash, generate_password_hash

HERE = os.path.dirname(os.path.abspath(__file__))
DB = os.path.join(HERE, "library.db")

# SQLite's 'now' is UTC. Singapore is UTC+8, so shift it, or books
# go overdue at 8 a.m. instead of midnight. This is our own fixed text,
# never user input, so it is safe to put into the SQL with an f-string.
TODAY = "date('now', '+8 hours')"

app = Flask(__name__, static_folder="static", static_url_path="")
with open(os.path.join(HERE, "secret.key")) as f:
    app.secret_key = f.read().strip()


def db():
    if "db" not in g:
        g.db = sqlite3.connect(DB)
        g.db.row_factory = sqlite3.Row
        g.db.execute("PRAGMA foreign_keys = ON")
    return g.db


@app.teardown_appcontext
def close_db(error):
    con = g.pop("db", None)
    if con is not None:
        con.close()


def rows(sql, params=()):
    return [dict(r) for r in db().execute(sql, params).fetchall()]


def me():
    """The logged-in user, or None."""
    if "user_id" not in session:
        return None
    return db().execute(
        "SELECT id, username, is_librarian FROM users WHERE id = ?",
        (session["user_id"],),
    ).fetchone()


def error(message, status):
    return {"error": message}, status


@app.get("/")
def home():
    return app.send_static_file("index.html")


# ---- Accounts ----

@app.post("/api/signup")
def signup():
    data = request.get_json(silent=True) or {}
    username = str(data.get("username", "")).strip().lower()
    password = str(data.get("password", ""))
    if not re.fullmatch(r"[a-z0-9_]{3,20}", username):
        return error("Use 3 to 20 letters, numbers or _.", 400)
    if len(password) < 8:
        return error("Use at least 8 characters.", 400)
    try:
        with db():
            cur = db().execute(
                "INSERT INTO users (username, pw_hash) VALUES (?, ?)",
                (username, generate_password_hash(password)),
            )
    except sqlite3.IntegrityError:
        return error("That username is taken.", 409)
    session["user_id"] = cur.lastrowid
    return {"username": username, "is_librarian": 0}, 201


@app.post("/api/login")
def login():
    data = request.get_json(silent=True) or {}
    username = str(data.get("username", "")).strip().lower()
    password = str(data.get("password", ""))
    user = db().execute(
        "SELECT id, username, pw_hash, is_librarian FROM users WHERE username = ?",
        (username,),
    ).fetchone()
    # Same message either way, so nobody learns which usernames exist.
    if user is None or not check_password_hash(user["pw_hash"], password):
        return error("Wrong username or password.", 401)
    session["user_id"] = user["id"]
    return {"username": user["username"], "is_librarian": user["is_librarian"]}


@app.post("/api/logout")
def logout():
    session.clear()
    return {"ok": True}


@app.get("/api/me")
def whoami():
    user = me()
    if user is None:
        return error("Not logged in.", 401)
    return {"username": user["username"], "is_librarian": user["is_librarian"]}


# ---- Books ----

@app.get("/api/books")
def list_books():
    return rows(
        "SELECT b.id, b.title, b.author, l.id IS NOT NULL AS on_loan "
        "FROM books b LEFT JOIN loans l "
        "ON l.book_id = b.id AND l.returned_on IS NULL "
        "ORDER BY b.title"
    )


@app.get("/api/books/<int:book_id>")
def one_book(book_id):
    found = rows("SELECT id, title, author FROM books WHERE id = ?", (book_id,))
    if not found:
        return error("No book with that id.", 404)
    return found[0]


@app.post("/api/books")
def add_book():
    user = me()
    if user is None or not user["is_librarian"]:
        return error("Only the librarian can add books.", 403)
    data = request.get_json(silent=True) or {}
    title = str(data.get("title", "")).strip()
    author = str(data.get("author", "")).strip()
    if not (1 <= len(title) <= 100 and 1 <= len(author) <= 100):
        return error("Give a title and an author, 100 characters at most.", 400)
    with db():
        cur = db().execute(
            "INSERT INTO books (title, author) VALUES (?, ?)", (title, author)
        )
    return {"id": cur.lastrowid, "title": title, "author": author}, 201


# ---- Loans ----

@app.get("/api/loans")
def my_loans():
    user = me()
    if user is None:
        return error("Log in first.", 401)
    return rows(
        "SELECT l.id, b.title, l.due_date, "
        f"l.due_date < {TODAY} AS overdue "
        "FROM loans l JOIN books b ON b.id = l.book_id "
        "WHERE l.user_id = ? AND l.returned_on IS NULL "
        "ORDER BY l.due_date",
        (user["id"],),
    )


@app.post("/api/loans")
def borrow():
    user = me()
    if user is None:
        return error("Log in first.", 401)
    data = request.get_json(silent=True) or {}
    book_id = data.get("book_id")
    if not isinstance(book_id, int):
        return error("Send a book_id number.", 400)
    if not rows("SELECT id FROM books WHERE id = ?", (book_id,)):
        return error("No book with that id.", 404)
    try:
        with db():
            cur = db().execute(
                "INSERT INTO loans (user_id, book_id, due_date) "
                f"VALUES (?, ?, date({TODAY}, '+14 days'))",
                (user["id"], book_id),
            )
    except sqlite3.IntegrityError:
        return error("Someone already has that book.", 409)
    return rows("SELECT id, due_date FROM loans WHERE id = ?", (cur.lastrowid,))[0], 201


@app.post("/api/loans/<int:loan_id>/return")
def give_back(loan_id):
    user = me()
    if user is None:
        return error("Log in first.", 401)
    with db():
        cur = db().execute(
            f"UPDATE loans SET returned_on = {TODAY} "
            "WHERE id = ? AND returned_on IS NULL AND (user_id = ? OR ? = 1)",
            (loan_id, user["id"], user["is_librarian"]),
        )
    if cur.rowcount == 0:
        return error("No open loan of yours with that id.", 404)
    return {"ok": True}


@app.get("/api/overdue")
def overdue():
    user = me()
    if user is None or not user["is_librarian"]:
        return error("Only the librarian can see this.", 403)
    return rows(
        "SELECT l.id, u.username, b.title, l.due_date "
        "FROM loans l "
        "JOIN users u ON u.id = l.user_id "
        "JOIN books b ON b.id = l.book_id "
        f"WHERE l.returned_on IS NULL AND l.due_date < {TODAY} "
        "ORDER BY l.due_date"
    )


if __name__ == "__main__":
    app.run(debug=True)

static/app.js

Every bit of text from the database goes into the page with textContent. Never innerHTML. So a book called <script> shows as text.

static/app.js
// The page side of the Class Library. It only talks to the API with fetch().
const $ = (id) => document.getElementById(id);
let user = null;

async function call(method, path, body) {
  const res = await fetch(path, {
    method,
    headers: body ? { "Content-Type": "application/json" } : {},
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = await res.json();
  if (!res.ok) throw new Error(data.error || "Something went wrong.");
  return data;
}

function say(text, bad) {
  $("msg").textContent = text;
  $("msg").className = bad ? "lib-msg bad" : "lib-msg";
}

function item(text, buttonText, onClick) {
  const li = document.createElement("li");
  const span = document.createElement("span");
  span.textContent = text; // textContent, never innerHTML, for anything typed
  li.append(span);
  if (buttonText) {
    const b = document.createElement("button");
    b.type = "button";
    b.textContent = buttonText;
    b.addEventListener("click", onClick);
    li.append(b);
  }
  return li;
}

async function showBooks() {
  const books = await call("GET", "/api/books");
  $("books").replaceChildren(...books.map((b) => {
    const label = `${b.title}, ${b.author}` + (b.on_loan ? " (out)" : "");
    if (!user || b.on_loan) return item(label);
    return item(label, "Borrow", () => borrow(b.id, b.title));
  }));
}

async function showLoans() {
  if (!user) return;
  const loans = await call("GET", "/api/loans");
  $("loans").replaceChildren(...(loans.length ? loans.map((l) =>
    item(`${l.title}, due ${l.due_date}` + (l.overdue ? " (overdue)" : ""), "Return", () => giveBack(l.id))
  ) : [item("Nothing borrowed.")]));
  if (user.is_librarian) {
    const late = await call("GET", "/api/overdue");
    $("overdue").replaceChildren(...(late.length ? late.map((l) =>
      item(`${l.title}: ${l.username}, due ${l.due_date}`, "Mark returned", () => giveBack(l.id))
    ) : [item("Nothing overdue.")]));
  }
}

function showUser() {
  $("who").textContent = user ? `Logged in as ${user.username}` : "Not logged in";
  $("logout").hidden = !user;
  $("auth").hidden = !!user;
  $("mine").hidden = !user;
  $("desk").hidden = !(user && user.is_librarian);
}

async function refresh() {
  showUser();
  await showBooks();
  await showLoans();
}

async function borrow(id, title) {
  try {
    const loan = await call("POST", "/api/loans", { book_id: id });
    say(`Borrowed ${title}. Due ${loan.due_date}.`);
  } catch (e) { say(e.message, true); }
  await refresh();
}

async function giveBack(id) {
  try {
    await call("POST", `/api/loans/${id}/return`);
    say("Returned.");
  } catch (e) { say(e.message, true); }
  await refresh();
}

$("auth").addEventListener("submit", async (e) => {
  e.preventDefault();
  const form = new FormData(e.target);
  const action = e.submitter ? e.submitter.dataset.action : "login";
  try {
    user = await call("POST", `/api/${action}`, {
      username: form.get("username"),
      password: form.get("password"),
    });
    e.target.reset();
    say(action === "signup" ? "Account made. You are logged in." : "Logged in.");
  } catch (err) { say(err.message, true); }
  await refresh();
});

$("logout").addEventListener("click", async () => {
  await call("POST", "/api/logout");
  user = null;
  say("Logged out.");
  await refresh();
});

$("add-book").addEventListener("submit", async (e) => {
  e.preventDefault();
  const form = new FormData(e.target);
  try {
    const book = await call("POST", "/api/books", { title: form.get("title"), author: form.get("author") });
    e.target.reset();
    say(`Added ${book.title}.`);
  } catch (err) { say(err.message, true); }
  await refresh();
});

(async () => {
  try { user = await call("GET", "/api/me"); } catch { user = null; }
  await refresh();
})();

Put it on PythonAnywhere

This is for the teacher's own account, not students'. Their terms ask for contract age, which is 18 in Singapore.

  1. Make a free account. Your app's address will end in .pythonanywhere.com.
  2. On the Files tab, make a folder library in your home folder. Upload the six files, with the three page files in library/static.
  3. Open a Bash console. Run cd library, then python3 setup_db.py.
  4. Make a virtualenv and install Flask in it, as PythonAnywhere's Flask help page shows.
  5. On the Web tab, add a new web app. Pick Manual configuration and the same Python version. Enter your virtualenv name.
  6. Open the WSGI file from the Web tab. Add your library folder to sys.path. Then add from app import app as application.
  7. Click Reload on the Web tab. Open your address.

Free accounts get one web app, which stops after a month unless you extend it. The Web tab has a button for that. There is also a 512 MiB disk limit, which a class library will never reach.

The app reads files with full paths built from __file__. On PythonAnywhere the server does not start in your folder. A plain "library.db" would make a new, empty database somewhere else.

How the twin on the app page differs

The app page runs a JavaScript copy of app.py. It is in server.js. Here is every difference I know of.

  • SQL: the same text, run by SQLite inside the browser through sql.js. Same placeholders, same index, same date maths.
  • Hashing: the twin uses werkzeug's pbkdf2:sha256:1000000 format, because browsers have no scrypt. I checked that check_password_hash in Python accepts a hash the twin made. So a twin user would log in fine in the real app.
  • Sessions: Flask signs a cookie. The twin keeps the user id in your browser's storage. There is nothing to sign, as there is no server to fool.
  • Transactions: sql.js saves every statement at once. Each twin route writes one row, so the result is the same.
  • Errors: Flask sends its 404 and 405 as HTML pages. The twin sends them as JSON, with the same status codes.
  • The page: the twin loads app.js unchanged. Only fetch() is pointed at the twin.
