The spreadsheet

I did all the work in one spreadsheet. Every number comes from a formula, so you can trace it back to the raw census file.

Download getting-to-school.xlsx

To open it in Google Sheets: in Google Drive, choose New, then File upload. Then open the file with Google Sheets. It also opens in Excel.

It has seven tabs. Each one does one job, from left to right:

  1. Read me: the question, the source and the licence.
  2. Raw: the census file exactly as downloaded. Nobody edits this tab.
  3. Groups: each of the 11 census ways of travel, and the group I put it in.
  4. Clean: the tidy table, 12 rows.
  5. Summary: my checks.
  6. Change log: the 8 notes from the data page.
  7. Class practice (made up): a fake class survey for practising cleaning and averages.

The formulas that do the work

Three formulas: one looks numbers up, one adds up a group, one turns it into a percent.

Groups tab: look up each number

=INDEX(Raw!$H$1:$H$13,MATCH($A2,Raw!$A$1:$A$13,0))

MATCH finds the row with this census label. INDEX takes the number from the Primary column, column H. If the census ever changes the row order, this still finds the right row.

Clean tab: add up each group

=SUMIF(Groups!$B$2:$B$12,$B2,Groups!C$2:C$12)

SUMIF adds the numbers for every census row in this group. For "MRT or LRT", that is three rows.

Clean tab: percent of the level

=C2/SUMIF($A$2:$A$13,$A2,$C$2:$C$13)

This divides by the total for that level, so primary and secondary each add up to 100%. The cell is formatted as a percent with 1 decimal place.

The Summary tab: my checks

Primary groups add up

=SUMIF(Clean!$A$2:$A$13,"Primary",Clean!$C$2:$C$13)

Mine: 245,456. Census: 245,456. Same? TRUE

Secondary groups add up

=SUMIF(Clean!$A$2:$A$13,"Secondary",Clean!$C$2:$C$13)

Mine: 173,710. Census: 173,710. Same? TRUE

Pre-primary and primary, no transport (%)

=ROUND((Raw!E13+Raw!H13)/(Raw!E2+Raw!H2)*100,1)

Mine: 43.0. Census: 43.0. Same? TRUE

Pre-primary and primary, car or taxi (%)

=ROUND((Raw!E8+Raw!E7+Raw!H8+Raw!H7)/(Raw!E2+Raw!H2)*100,1)

Mine: 22.1. Census: 22.0. Same? FALSE

Secondary, public bus only (%)

=ROUND(Raw!K3/Raw!K2*100,1)

Mine: 36.9. Census: 36.9. Same? TRUE

The FALSE is real. I left it in. A check that always says TRUE teaches nothing.

Practice tab: a made-up class survey

This data is made up. These are not real pupils. I wrote it so my class can practise cleaning before they see their own slips.

Download the messy made-up survey as a CSV file

Slip 19 says 200 minutes. That is over 3 hours, so it is almost certainly a slip of the pen. But the slips have no names, so I can't ask. I leave it blank. That is the price of keeping it anonymous, and I think it is worth it.

The summary formulas

WhatFormulaResult
How many numbers=COUNT(D3:D33)27
Average (mean)=ROUND(AVERAGE(D3:D33),1)18.0 min
Middle value (median)=MEDIAN(D3:D33)15 min
Shortest=MIN(D3:D33)5 min
Longest=MAX(D3:D33)45 min
Range=MAX(D3:D33)-MIN(D3:D33)40 min

The average is 18 minutes but the middle value is 15. A few long trips pull the average up. The middle value stays put.

P6 pupils learn the average as the total divided by how many. The median is not in the primary syllabus, so I call it the middle value. Pupils find it by lining up number cards from shortest to longest. That is a good moment to ask: which number tells a new pupil what to expect?

Then the count by way of travel: Walk 12, Car 6, School bus 5, Public bus 5, MRT and bus 1, Prefer not to say 1. The last two are under 5. So they become "Other or not said: 2" before the class sees the chart.
